# AU Natives Garden

Australian natives-focused web app for species reference, seed germination tracking, purchase/wishlist planning, garden sites, and site-fit suggestions.

- **App:** [`web/`](web/)
- **Legacy HTML tracker:** [`standalone_native_seed_tracker.html`](standalone_native_seed_tracker.html)
- **Database:** [`supabase/migrations/001_initial.sql`](supabase/migrations/001_initial.sql)
- **Setup:** [`web/SETUP.md`](web/SETUP.md)

```bash
cd web
npm install
npm run dev
```

## GitHub Pages

Pushing to `main` builds and deploys the app via GitHub Actions.

Live site: https://iterationhubau.github.io/australian-natives-garden/
